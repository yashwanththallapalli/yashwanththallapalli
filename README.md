## Featured project

**[computer-use-automation](https://github.com/yashwanththallapalli/computer-use-automation)** — An LLM explores a legacy bank back-office app once; that run is frozen into a typed, versioned *capability artifact* and replayed deterministically with no model in the loop. Guardrails, evidence logging, outcome classification, and human handoff on the live session. ~90 tests, design tradeoffs documented in REPORT.md.
